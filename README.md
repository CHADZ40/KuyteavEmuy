# គុយទាវឆ្ញាញ់ចែមួយ

A Khmer restaurant website for **ហាងគុយទាវឆ្ញាញ់ចែមួយ** in Oudong. The page brings the menu, the restaurant's story, a featured Facebook Reel, contact links, and the map together in one simple place.

## About the site

- Khmer-first content with Khmer web fonts
- Warm orange menu cards, a dark blue contact section, and restaurant photography
- Responsive layout for phones and larger screens
- Responsive gallery of four Facebook videos/Reels with a link to the full Reels page
- Direct links for Facebook, TikTok, Telegram, phone, and Google Maps

## Open locally

No build tools or package installation are required. Open `index.html` in a browser, or serve this folder with any static file server. For example, if Python is installed:

```sh
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Project files

```text
.
├── index.html       # Page content and links
├── style.css        # Layout, colors, and responsive styles
└── images/          # Restaurant, menu, and history photos
```

The Facebook videos are embedded from their supplied URLs. Facebook, Google Maps, Font Awesome, and Google Fonts need an internet connection to load. Update the embeds in the media section of `index.html` when adding or replacing videos.

## Customize

Edit the Khmer copy and contact details in `index.html`. Adjust the visual theme and mobile breakpoints in `style.css`. Keep new image assets in `images/` and use descriptive filenames.
